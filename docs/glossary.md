# Glossary

| Term | Meaning here |
|---|---|
| **Asset** | A document your team can use or send: deck, one pager, blog, script, template, guide, webinar, positioning doc |
| **Vehicle** | An asset *type* (deck, one pager, script and so on). The report asks which vehicles work at which stage |
| **Claim** | One distinct message inside an asset, in short form, with an ID. The unit of evidence |
| **Message and theme** | Claims grouped the way you train your team. A message is a group of claims. A theme is a group of messages |
| **Scope: exclusive, shared, generic** | A claim carried by one asset (exclusive), two or three (shared), or four or more (generic). Exclusive claims name the asset with high confidence |
| **Era** | A period of your messaging history. Useful to tell an old version in use from a current one |
| **Field born** | A message said in the field before any document carried it, or never carried by any |
| **Gap** | Anything said that no claim covers |
| **Fidelity** | How faithful a line is to a claim: verbatim, near verbatim, faithful paraphrase, drifted (the meaning moved), contradicted |
| **Event** | What happened to a claim in a call: used, shown, sent, mentioned, requested, missing, buyer echo, buyer pushback, field born, rep built, lookalike, internal |
| **Lookalike** | Something that sounds like your asset but comes from somewhere else |
| **Reader** | A fresh agent that reads calls and writes rows |
| **Adjudicator** | A fresh agent that rules on items only one reader found |
| **Spec** | The written instructions an agent follows, versioned |
| **Retro** | The weekly review of errors, tagged fix now, watch or no change |
| **Label review** | Weekly human review of the ten most uncertain gap and signal labels |
| **Spot check** | Weekly human review of about ten adjudicated items |
| **Answer key** | A list of moments where a claim should be found. A floor, not the truth |
| **Recall** | The share of the key's moments a reader found ("did it miss things?") |
| **Precision** | The share of the reader's rows that are right ("did it make things up?"). Misleading against an incomplete key |
| **Call level / turn level** | Call level asks whether a claim was found anywhere in the call. Turn level asks whether it was found at the exact turn |
| **Agreement** | How often two readers find the same pairs. A drop is a warning light |
| **Guardrail** | A minimum number that must hold when you change a setting |
| **Token** | The unit AI work is measured and billed in, roughly three quarters of a word |
| **Effort** | How hard the model thinks before answering (low, medium, high) |
| **Subagent** | A separate Claude started by your main session, with its own instructions and no memory of your conversation |
| **Context** | What an agent can see at once. Splitting a long week into halves keeps each reader's context smaller |
| **Scratchpad** | A temporary folder that disappears. Never keep outputs there |
| **Churn mitigation** | Asking what would keep a customer who may stop using the product |
| **Win back** | After a customer decided to leave, asking whether they would come back |
| **Renewal question** | Asking whether the customer would renew. Not the same as churn mitigation |
